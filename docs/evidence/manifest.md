- The branch contains the implemented UI, deterministic engine, typed API, proposed RLS migration, tests, and documentation.
- Local commands can prove installability, test outcomes, type/lint state, build output, and browser behaviour on this machine.
- Local proof cannot establish GitHub visibility, hosted CI, deployment, provider configuration, users, customers, commercial outcomes, or live security.

## GitHub truth

- Repository visibility, branch existence, commit identity, PR state, and hosted check execution require GitHub evidence.
- A pushed branch is not merged source truth.
- A pull request is not deployment or production proof.
